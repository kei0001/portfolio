# INFLATION / CAPITAL

物価上昇・手取りの上昇・株式の名目リターンを変更し、家計負担増を株式の実質収益で相殺するのに必要な資産額を試算する、日本語のレスポンシブWebアプリです。

## 使い方

`index.html` をブラウザで開くだけです。ビルド不要、依存ライブラリ不要。共有ボタンからクエリパラメータ付きURLをコピーできます。

## 数式

- 家計負担増（万円）: `生活費 × インフレ率 - 手取り × 手取り増加率`
- 実質株式リターン: `(1 + 株式名目利回り) / (1 + インフレ率) - 1`
- 必要資産: 家計負担増が正かつ実質リターンが正なら `家計負担増 / 実質リターン`。家計負担増が非正なら0。家計負担増が正で実質リターンが非正なら相殺不可。

## 留意点

単年の簡易モデル。家計の名目差額と株式の実質損益を組み合わせるため、厳密な同一購買力単位の損益計算ではありません。株式のリターンはインフレによる利益とは限りません。実際の投資には下落、税金、手数料、現金保有や借入金などが影響します。
